Decentralized Medical Data Exchange

Encrypted patient records stored on Walrus, with cryptographic access control managed on Sui via Tatum infrastructure.

01
Encrypt Record
AES-256-CBC encryption
⏸
Patient's medical record is encrypted locally before leaving the device.
02
Upload to Walrus
Decentralized blob storage
⏸
Encrypted payload is pushed as an immutable blob to Walrus decentralized storage.
03
Register on Sui
Via Tatum RPC
⏸
Blob metadata and file hash are recorded on-chain via Tatum's Sui infrastructure.
04
Grant Access
Time-bound permission
⏸
Patient grants a doctor time-bound cryptographic access to the medical record.
05
Revoke Access
Patient-controlled
⏸
Patient revokes the doctor's access. All state changes are logged immutably.
06
Audit Trail
Tatum Data API
⏸
Complete access history retrieved via Tatum's indexed data endpoints.
07
Retrieve & Decrypt
Walrus → plaintext
⏸
Authorized doctor retrieves the blob from Walrus and decrypts the patient record.
